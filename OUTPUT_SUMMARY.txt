(d) Open on my phone:
    After running the server, the terminal will display the LAN URL and a QR code.
    Connect your phone to the same Wi-Fi network, scan the QR code or visit the URL (use https:// if SSL certificates were generated, otherwise http://).
    Note: For mobile camera access, HTTPS is required. If you did not generate SSL certificates (because mkcert is not installed), you will need to install mkcert and re-run the certificate generation step.

MANUAL STEPS:
1. Install mkcert if you want to use HTTPS for mobile camera access:
   - Windows: choco install mkcert
   - macOS: brew install mkcert
   - Linux: Follow instructions at https://github.com/FiloSottile/mkcert#installation
2. After installing mkcert, run the script to generate certificates:
   - Windows: python scripts\make_cert.py
   - Linux/macOS: python scripts/make_cert.py
3. If you wish to use notification providers other than console, obtain the necessary API keys and tokens and set them in the .env file (copy from .env.example).
4. Adjust session timings, recognition threshold, and other settings in the Settings page of the application after logging in.
